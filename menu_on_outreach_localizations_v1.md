# Menu-On Outreach Localizations

**Schema:** 1.0  
**Encoding:** UTF-8  

## Placeholders

- `{{restaurant_name}}` — Restaurant name
- `{{landing_url}}` — Personal landing/menu URL
- `{{admin_url}}` — Admin panel URL

## Country mapping

- `AT` → `de` (Deutsch)
- `DE` → `de` (Deutsch)
- `ES` → `es` (Español)
- `PT` → `pt` (Português)
- `IT` → `it` (Italiano)
- `CZ` → `cs` (Čeština)
- `HU` → `hu` (Magyar)
- `PL` → `pl` (Polski)
- `NL` → `nl` (Nederlands)
- `FR` → `fr` (Français)
- `HR` → `hr` (Hrvatski)
- `GB` → `en` (English)
- `IE` → `en` (English)
- `US` → `en` (English)
- `CA` → `en` (English)
- `AU` → `en` (English)
- `NZ` → `en` (English)

> Belgium, Switzerland and Luxembourg are intentionally not auto-mapped because they are multilingual.
